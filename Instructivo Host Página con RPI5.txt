====================================================================
INSTRUCTIVO DE CONFIGURACIÓN: SERVIDOR WEB FLASK Y COMUNICACIÓN SERIAL
Hardware: Raspberry Pi 5
====================================================================

PASO 1: INSTALACIÓN DE DEPENDENCIAS
--------------------------------------------------------------------
1. Actualizar la lista de paquetes del sistema operativo:
   Comando: sudo apt update

2. Instalar el entorno web (Flask) y la librería de comunicación (pyserial):
   Comando: sudo apt install python3-flask python3-serial -y (-y: le dice que sí a cualquier pregunta que el proceso realice).


PASO 2: HABILITAR EL PUERTO SERIAL (UART) DESDE EL SISTEMA
--------------------------------------------------------------------
1. Abrir la herramienta de configuración de Raspberry:
   Comando: sudo raspi-config

2. Navegar en el menú usando las flechas del teclado:
   - Seleccionar: "3 Interface Options" y presionar Enter.
   - Seleccionar: "I5 Serial Port" y presionar Enter.

3. Responder a las preguntas de seguridad:
   - "Would you like a login shell to be accessible over serial?": Seleccionar <No>
   - "Would you like the serial port hardware to be enabled?": Seleccionar <Yes>

4. Confirmar, salir (Finish) y reiniciar la Raspberry Pi (Reboot) cuando el sistema lo pregunte.


PASO 3: OTORGAR PERMISOS AL USUARIO
--------------------------------------------------------------------
1. Para que el código Python pueda escribir en el puerto serial sin pedir contraseña de administrador, el usuario debe pertenecer al grupo "dialout".
   Comando: sudo usermod -a -G dialout grupo4

   (Nota: Si se usa otra Raspberry con otro nombre de usuario, cambiar "grupo4" por el usuario correspondiente).


PASO 4: ESTRUCTURA OBLIGATORIA DE ARCHIVOS
--------------------------------------------------------------------
Verificar que los archivos del proyecto estén organizados estrictamente de la siguiente manera antes de ejecutar el código, donde templates es una subcarpeta en Proyecto:

/home/grupo4/Proyecto/ (o la ruta donde estén trabajando)
  |-- server.py
  |-- templates/
        |-- index.html


PASO 5: OBTENER LA DIRECCIÓN IP Y ARRANCAR EL SERVIDOR
--------------------------------------------------------------------
1. Averiguar la dirección IP local de la Raspberry Pi:
   Comando: hostname -I
   (Anotar el número resultante, ej. 192.168.x.x)

2. Posicionarse en la carpeta del proyecto y ejecutar el código de Python:
   Comando abrir carpeta: cd Nombre_Carpeta
   Comando ejecución: python3 server.py

   El servidor indicará que está corriendo en el puerto 5000 (Running on all addresses 0.0.0.0).


PASO 6: USO DE LA PÁGINA WEB
--------------------------------------------------------------------
1. Conectar una computadora o teléfono a la MISMA RED Wi-Fi que la Raspberry Pi.
2. Abrir un navegador web (Chrome, Safari, etc.). (En caso de estar en VSCode, debería salir una pestaña emergente para abrir la página en el navegador automáticamente, por lo que se puede omitir el paso 3.)
3. Escribir la IP obtenida en el Paso 5 seguida del puerto 5000.
   Formato: http://[Direccion_IP]:5000
   Ejemplo: http://192.168.1.99:5000
