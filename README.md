## Descripción del Proyecto

Este proyecto de diseño en ingeniería propone el desarrollo de un sistema de **percheros circulares inteligentes**.

El sistema está inspirado en percheros rotatorios donde el usuario **no necesita desplazarse** para acceder a las prendas. En su lugar, el sistema posiciona automáticamente el perchero solicitado frente al usuario.
